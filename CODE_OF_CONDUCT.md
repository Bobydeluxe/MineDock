# Code de conduite

Participez avec respect et bonne foi. Les désaccords techniques doivent rester centrés sur les faits et le code. Le harcèlement, les attaques personnelles et la divulgation de données privées ne sont pas acceptés. Les mainteneurs peuvent retirer un contenu ou restreindre une participation contraire à ces règles. Signalez les problèmes par un canal privé des mainteneurs une fois le projet publié.
