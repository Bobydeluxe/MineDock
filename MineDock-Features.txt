MINEDOCK — COMPLETE FEATURE LIST
Version: 0.2.0 beta
Project status: 3 October 2026

This document distinguishes implemented features, current limitations and
planned improvements. Planned features are not available in the beta.
English is the primary project language and the application's default.

======================================================================
1. APPLICATION AND FIRST LAUNCH — IMPLEMENTED
======================================================================

- Desktop application with a graphical interface.
- Local management of multiple Minecraft servers.
- No mandatory cloud account.
- Four-step first-launch wizard.
- Six languages: English, French, German, Spanish, Portuguese and Italian.
- Immediate language preview during onboarding.
- Language selection in Settings, saved between launches.
- Existing language preferences preserved when upgrading.
- Localized MineDock errors, crash explanations and activity labels.
- Light, dark or system-synchronized theme.
- Server and backup folder selection.
- Platform, architecture and available-resource diagnostics.
- Total memory, free memory and free disk-space display.
- Detection of existing Java installations.
- Informational Docker detection, without a Docker server runner.
- Local-network IP detection and available-port discovery.
- Persistent preferences.
- Only one MineDock instance at a time.
- Offline local administration after complete installation and first server
  startup; downloads require Internet access.
- Optional temporary sleep prevention while servers run.

======================================================================
2. DASHBOARD AND NAVIGATION — IMPLEMENTED
======================================================================

- Overview of all servers.
- Cards displaying server name, engine, version and status.
- Active-server and connected-player counts.
- Used memory and server storage display.
- Server search by name.
- All, online and stopped server filters.
- Sidebar with direct access to each server.
- Quick start, stop and backup actions.
- Display/copy local and LAN connection addresses.
- Activity history and access to backups.
- Success notifications and error messages.
- Navigation palette: Ctrl+K.
- Open settings: Ctrl+,.

- Layout adapts to different window sizes.
- Separate, explicitly identified demo mode for development.

3. SERVER CREATION AND INSTALLATION — IMPLEMENTED
======================================================================

- Four-step server creation wizard.
- Server name selection.
- Paper or Vanilla engine selection.
- Version lists from official Mojang and PaperMC catalogs.
- Vanilla release versions; snapshots hidden in this beta.
- Stable Paper build selection.
- Pinned Minecraft version and Paper build for installation.

- Minecraft port selection.
- Minecraft/RCON port conflict checks across profiles.
- Initial game mode and difficulty configuration.
- Maximum player count.
- PvP and whitelist controls.
- View/simulation distance settings.
- World seed and server welcome message.
- Minecraft account verification through online-mode.
- Automatic startup and crash recovery options.
- Pre-creation summary.
- Minecraft EULA link and explicit acceptance checkbox.
- Recording of the consent personally given in the wizard.
- Automatic installation of the appropriate Java runtime when needed.
- Official Minecraft/Paper JAR downloads.
- Server folder and configuration creation.
- Download progress, received bytes and speed display.
- Cancellation of an ongoing download.
- Download checksum verification before installation.
- Incomplete profiles retained after failed installation.
- Retry button for incomplete installation using the same pinned version/build,

======================================================================
4. JAVA AND RUNTIMES — IMPLEMENTED
======================================================================

- Java discovery through JAVA_HOME, accessible executables and managed runtimes.
- Isolated Temurin/Adoptium runtime downloads.
- Java major versions 8, 11, 16, 17, 21 and 25.
- Required Java version determined from engine/Minecraft version.
- Separate Vanilla and Paper Java requirements.
- Available-runtime list in Settings.
- Runtime installation from the interface.
- Compatible runtime selection for each server.
- Download verification and controlled extraction of Java archives.
- Distributed application requires no Node or pnpm installation.

======================================================================
5. STARTUP, SHUTDOWN AND SUPERVISION — IMPLEMENTED
======================================================================

- Independent Java process for every server.
- Start, stop and restart from the interface.
- Automatic startup of configured profiles when MineDock opens.
- Runtime, JAR, EULA and port checks before startup.
- Installing, stopped, starting, online, stopping, crashed, backing-up and
  restoring states.
- Successful startup detected from real server output.
- Five-minute startup timeout.
- PID, start time and exit code tracking.
- save-all flush before shutdown when RCON is available.
- stop command and graceful shutdown waiting.
- Forced termination as a last resort after the shutdown timeout.
- Expected shutdown distinguished from crashes.
- Crash detection with explanations for recognized errors.
- Optional automatic crash recovery with 15- then 30-second delays.
- Recovery suspended after three crashes in ten minutes.
- Serialization of sensitive operations on the same server.
- Detection of an old active PID after abrupt manager termination.
- Blocking/explanation when an old process may still use a server.
- Supervised server shutdown when MineDock closes normally.

======================================================================
10. BACKUPS AND RESTORATION — IMPLEMENTED
======================================================================

- Manual complete-server backups.
- Global and per-server backup lists.
- ZIP archives indexed in SQLite.
- Name, date, size and reason display.
- SHA-256 integrity verification.
- Native backup export.
- Confirmed backup deletion.
- Live backups using save-off, save-all flush and save-on.
- Safety shutdown if world-saving resumption cannot be confirmed.
- Free-space checks before backup/restoration preparation.
- Restoration requires a stopped server and exact confirmation name.
- Safety backup before every restore.
- Checksum verification before extraction.
- Staged extraction with archive-entry validation.
- Prepared-folder swap and rollback for relevant failures.
- Managed-plugin metadata restoration.
- Profile settings synchronized with restored properties.
- Current profile ports retained and RCON secret reinjected on restore.
- rcon.password and session locks excluded from generated archives.
- No automatic purging of manual backups.
- Current limit: 64 GB uncompressed per backup.

14. DATA PROTECTION AND SECURITY — IMPLEMENTED
======================================================================

- Isolated Electron renderer, sandbox enabled, no renderer Node access.
- Limited preload API and IPC validation.
- Typed input validation.
- Java process launch without an intermediate shell.
- No public administration panel exposed by MineDock.
- HTTPS downloads with host/redirect validation.
- Bounded download deadlines and sizes.
- Temporary files and checksum validation before replacement.
- Directory traversal and dangerous-filename protection.
- Symlink/junction checks for file operations.
- Controlled ZIP extraction rejecting malicious/ambiguous entries.
- Random RCON password encrypted in the local database.
- safeStorage when available, with local AES-256-GCM fallback.
- Secret/sensitive-data redaction in relevant output.
- SQLite versioned migrations, transactions and integrity checks.
- Periodic consistent SQLite snapshots.

17. VALIDATION STATUS AND BETA LIMITATIONS
======================================================================

- Windows 11 x64: build and packaged application launch verified.
- Baseline: 52 unit/integration tests and two UI journeys passed.
- The multilingual update adds catalog and language-persistence tests;
  current results are recorded in docs/validation.md.
- Strict TypeScript, lint and Windows packaging are release checks.
- Real Java/Paper downloads verified; Paper bootstrap tested up to its EULA
  gate with eula=false.
- A real Minecraft client connection/gameplay session still needs validation
  after personal EULA acceptance in the wizard.
- Windows distributions are currently unsigned.
- Windows/Linux/macOS CI packaging succeeds, but packaging is not gameplay
  validation or proof of every native integration on those systems.
- Unknown external errors and OS file dialogs may retain their own language.
- MineDock must remain open to supervise servers and execute tasks.
- MineDock does not automatically configure firewalls or router port forwarding.
