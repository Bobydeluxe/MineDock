# Engine symbols

Eight original MineDock SVG illustrations under the project MIT license. They identify server engines without copying official logos. Engine names belong to their respective projects; these illustrations do not imply endorsement. The symbols ship locally and require no network request.

The visual identity revision removes the shared rounded background tile. Each engine retains its original line drawing, individual color and fixed view box on a transparent background. SVG geometry and image dimensions are unchanged, so the revision does not move engine choices, sidebar entries or server-card controls.
