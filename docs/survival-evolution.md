# Friends survival evolution — MineDock 0.4.0

This ledger records the survival features introduced in 0.4.0 and retained in the current **MineDock 0.4.1** release. The current gallery and controls include the [0.4.1 interface and customization](design/reference-041/README.md).

MineDock 0.4.0 extends the existing core. It preserves eight engines, migrations 1–6, Electron sandbox/context isolation, strict TypeScript, warm light/neutral charcoal dark and bundled EN/FR/DE/ES/PT/IT. English remains the project/default language. The current public release is [0.4.1](https://github.com/Bobydeluxe/MineDock/releases/tag/v0.4.1). [PR #7](https://github.com/Bobydeluxe/MineDock/pull/7) records implementation and review.

## Implementation ledger

| Stage                       | Concrete implementation                                                                                                                                                                                  | Boundaries                                                                                                                                                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1 — Content                 | World-scoped Modrinth datapacks/resource packs, exact version/dependency plans, local/manual offline inventory, enable/disable/remove, server URL/SHA-1 and actual hashes; plugins reuse the mod manager | Upstream metadata is compatibility evidence, not runtime proof. Local files need a URL serving identical bytes. Optional dependencies remain optional                      |
| 2 — Health                  | Actual runtime/port/content/disk/backup/process checks, bounded deterministic crash evidence, possible candidates, persisted notices/read/preferences/native delivery                                    | 400 notices, fifteen-minute grouping, thirty-second process thresholds; native notices default off. No invented heap/swap or weak causal certainty                         |
| 3 — Players                 | Observed first/last/sessions, today/7/30-day totals, local notes, official cached skins, real whitelist/moderation                                                                                       | 180 days/20,000 sessions per server, 200 detail sessions, 4,000-character notes. Unobserved/offline identities remain unavailable                                          |
| 4 — Backups                 | Immutable SHA-256 file deduplication, verified manifests, exact partial previews, full current-state safety ZIP, mounted write/space probe; separate default-on safety policies                          | Stopped snapshots, 200,000 files/64 GB. No snapshot deletion/GC or legacy-ZIP partial restore. NAS uses the OS mount                                                       |
| 5 — Migration               | Official engine/runtime/content/version analysis, downgrade/unknown refusal, recoverable Minecraft/Paper/Purpur change, full/fresh-world clones and independent ports                                    | World/config preservation is not gameplay proof. | 6 — Console                 | Contextual localized suggestions, reliable categories, plain/gzip real-log search, cancellable presets/custom macros with operation locking                                                              | 40 files/16 MB, 2 MB/file, 500 output lines; 20 macros/20 steps/600-second delays. Unreliable dates stay unknown                                                           |
| 7 — Performance             | Host-aware RAM, Java-aware standard/G1/allowlisted custom flags, recognized Paper/Purpur TPS/MSPT, seven-day aggregation and lag/log context                                                             | Working set is not heap. | 8 — Configuration           | Searchable properties, existing bounded YAML/JSON primitives/comments, encrypted history/stale-write refusal, read-only advice, loopback maps, consented external observer                               | History: 10/file, 200/server, 20 MB/server, 90 days. No universal plugin path rewriting; world/player privacy requires review                        |
| 10 — Docs/site/distribution | Beginner guide, changelog/features/security review, refreshed native gallery/GIF, static public site, native release validation and reviewed PR                                                          | Exact source/release/native test boundaries are recorded in validation; OS-installed validation remains distinct from native packaged execution                            |

## Persistence

Migrations 7–11 append notices, player sessions/notes, incremental manifests, performance/lag samples and encrypted configuration versions. Existing migration SQL is unchanged. Validated profiles persist packs, JVM presets and macros. A database snapshot precedes schema upgrades; full backups and recoverable operation journals remain available.
