# Historical validation records

These dated records document the exact application/source commits, native builds, tests, migrations and public artifacts observed at each checkpoint. Their URLs, identifiers, command names and file paths are historical evidence, not current instructions or proof of present availability.

The separate hosting project was abandoned on 11 October 2026. Records containing old hosting URLs or deployment/export checks are retained unchanged for traceability; the corresponding sources, workflows, guides and web-only images have been removed. Deleted source/capture files can be inspected at their recorded commit or in the [pre-cleanup tree](https://github.com/Bobydeluxe/MineDock/tree/aad68d41bb2d1d890ec802c9a9905756636cfbb5).

Use the root [README](../../README.md) for the official GitHub homepage/downloads, the [current validation summary](../validation.md) for scope, the desktop [Privacy Policy](../PRIVACY_POLICY.md) for data practices and [Code signing policy](../code-signing-policy.md) for actual signing status. Historical records do not authorize publishing a new version or changing released bytes.
