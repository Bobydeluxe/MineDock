What this website provides

This website introduces MineDock, a free, independent, open-source desktop application. It links to documentation, source code, release downloads and security information. MineDock runs local Minecraft servers on the user's machine; it does not sell server hosting, subscriptions or a paid online service.

The currently public application is version 0.5.0. New player/world captures show that released application; retained 0.4.1 baseline screens are explicitly identified. Captions disclose saved QA data and isolated server conditions.
