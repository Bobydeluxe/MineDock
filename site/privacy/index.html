The site source sets no cookies and uses no local storage, advertising identifiers, fingerprinting or tracking pixels. No consent banner is added for technologies the site does not use. Host response behavior must also be checked on the live GitHub Pages deployment before launch.

Links, reports and search engines

GitHub documentation, issues and downloads open only when you follow links. Public issue reports can expose your username and what you submit. Avoid posting private logs, player data or credentials. Consult GitHub's own policy before using its services.

Search Console is not connected yet. Planned ownership verification uses a static HTML file or meta tag, not a visitor analytics script. Search engines may crawl public pages independently. No Google Analytics or Tag Manager is included.
