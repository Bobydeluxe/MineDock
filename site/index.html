BEFORE YOUR FRIENDS JOIN

A few useful answers.

MineDock manages your local server. You keep control of the machine, storage and network access.

Does MineDock host my server?

The server runs on your own computer. Friends can join on your local network; Internet connections depend on your network, firewall and port forwarding. MineDock does not sell cloud hosting.

Can Java and Bedrock friends play together?

Supported Java engines can use Geyser/Floodgate. Client versions, authentication and network access still need to be compatible; broad multiplayer gameplay has not yet been fully validated.

Will an update keep my worlds?

Keep your existing storage folders and use the same OS account. MineDock reuses and backs up its SQLite database before migration. The old 0.3.0 Windows automatic launcher may fail; open the verified newer portable or Setup package manually in that case.

What are the current limits?

Incremental snapshot deletion and shared-object garbage collection are not available yet. Complex engine configuration stays in the text editor. RAM is process working set, not JVM heap. Live maps, full multiplayer sessions and installation/upgrades on all operating systems have separate validation gaps.

Which languages are included?

English is the default. French, German, Spanish, Portuguese and Italian are also available inside MineDock.
