A FEW THINGS TO KNOW

Before you get started.

Is MineDock a hosting service?

No. The Minecraft server runs on your own computer. You provide the hardware, a Minecraft client and the network connection. MineDock helps you manage the server locally.

Can my friends connect from outside my home?

Yes, with suitable network configuration. MineDock does not automatically change your router or firewall. The reachability tool distinguishes local connectivity from an external observer, and asks before sharing your address.

Do I need to install Java or Node?

End-user packages include Electron; you do not need Node or pnpm. MineDock can download a suitable managed Java runtime for supported Java servers. Some engines have their own platform requirements.

Which features are in the download today?

MineDock 0.4.0 includes the friends survival features shown here. Screenshots come from the real desktop app with isolated QA records. Read the release notes for downloads, checksums and known limits.

Read the 0.4.0 release notes ↗
Why does Windows or macOS warn about the app?

Current packages have no Windows or Apple signing certificate. Download only from the project release page, read its notes and compare the published SHA-256 checksums. Signed update metadata is separate from operating-system code signing.

Can I move my server to another computer?

The .minedock package copies selected world, content and configuration data with a verified manifest. The destination prepares its own official engine and runtime. Default export excludes known secrets and arbitrary plugin configurations; review the documented limits before sharing.
